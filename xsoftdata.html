Biznes hesabat tətbiqi · Son yenilənmə: 3 oktyabr 2026

XSoftData — XSoft 1C sistemi quraşdırılmış müəssisələr üçün hesabat və analitika tətbiqidir: dövriyyə, satış dinamikası, kontragent hesablaşmaları və sənəd detalları telefonda görünür.

Vacib: tətbiq sifarişlə işləyən biznes alətidir. Tam istifadə üçün aktivasiya açarı və müəssisənin öz XSoft 1C serveri lazımdır. Serveri olmayan istifadəçi tətbiqi Demo / Baxış rejimi ilə gəzə bilər.

Demo / Baxış rejimi

Lisenziyası və serveri olmayanlar tətbiqin necə işlədiyini nümunə məlumatla görə bilər:

  1. Tətbiqi açın — ilk ekran lisenziya ekranıdır.
  2. «Demo / Baxış rejimi»nə toxunun.
  3. İstənilən 4 rəqəmli PIN daxil edin.
  4. Tətbiq nümunə məlumatla açılır — real server tələb olunmur.

Demo rejimində heç bir şəbəkə sorğusu göndərilmir, məlumat yalnız nümunədir.

Lisenziya necə alınır

Aktivasiya açarı cihaza bağlı verilir. Açar üçün bizə yazın — müəssisənin adı və istifadə edəcəyiniz cihazların sayını qeyd edin.

Tez-tez verilən suallar

Serverə qoşulmur, «əlaqə yoxdur» yazır

  • Telefon serverlə eyni şəbəkədədirmi (Wi-Fi) — yoxsa xaricdən girişin açıq olduğundan əmin olun.
  • Ünvan, port və baza adı düzgün yazılıbmı.
  • iOS ilk qoşulmada «yerli şəbəkədəki cihazları tapmaq» icazəsini istəyir. «İmtina» verilsə qoşulma işləmir → Ayarlar → XSoftData → Yerli şəbəkə açarını yandırın.
  • 1C HTTP servisi işləyirmi və istifadəçi/parol düzgündürmü.

Cihazı dəyişdim / tətbiqi yenidən qurdum, lisenziya itdi

Aktivasiya cihaz identifikatoruna bağlıdır. iOS-da tətbiq tamamilə silinib yenidən qurulduqda bu identifikator dəyişir — bu halda açar yenidən lazım olur. Bizə yazın, açarı yeniləyək.

PIN-i unutdum

PIN cihazda şifrəli saxlanılır və bərpa edilə bilmir. Tətbiqi silib yenidən quraşdırın, sonra lisenziya açarı ilə yenidən daxil olun.

Hesabatı necə paylaşıram

Hesabatlar PDF və Excel kimi çıxarılır, sonra telefonun standart paylaşma pəncərəsi ilə göndərilir. Fayl yalnız sizin cihazınızda yaranır.
